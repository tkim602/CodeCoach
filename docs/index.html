What it does

Help for the exact moment you would normally give up and search the answer.

Progressive hints

Start with a light nudge. Move to an algorithm direction or a concrete next step only when you need it. You stay in control of how much gets revealed.

Code review and debugging

Review the approach you already wrote, including time and space complexity, edge cases, runtime errors, selected lines, and visible failed-test output.

Wrong-answer notes

Turn a failed attempt into a short record of what went wrong, what fixed it, and what should be remembered the next time the same pattern appears.

Weakness tracking

Spot recurring mistakes such as binary-search boundaries, traversal errors, off-by-one bugs, and repeated implementation slips instead of treating every failed problem as unrelated.

Review planning

Save failed problems and revisit them with context. The point is not to solve more problems every day; it is to stop making the same mistakes.

Local-first

Your practice history stays under your control.

Your OpenAI API key, saved code snapshots, wrong-answer notes, settings, and local study history are stored in your browser. AI requests go directly from the extension to OpenAI using your own key. Optional account and learning-metadata sync is only used when you enable it.

FAQ

Before you install.

Does CodeCoach give full LeetCode solutions?

The coaching flow is built around progressive help instead of immediately returning complete accepted code. You choose how much guidance to reveal.

Does CodeCoach work on Programmers?

Yes. CodeCoach supports both LeetCode and Programmers problem pages.

Do I need an OpenAI API key?

Yes for AI-powered coaching features. The key is stored locally in your browser and requests are sent directly to OpenAI.

Is CodeCoach meant for live coding assessments?

No. CodeCoach is a practice tool and is not intended for active contests, certifications, hiring tests, private assessments, or similar evaluations.
