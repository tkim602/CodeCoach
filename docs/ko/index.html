정답을 검색하고 싶어지는 그 순간에 필요한 도움만 제공합니다.

단계별 힌트

처음에는 작은 힌트부터 시작합니다. 부족할 때만 알고리즘 방향이나 더 구체적인 다음 단계를 확인할 수 있어, 어느 정도까지 볼지 직접 정할 수 있습니다.

코드 리뷰와 디버깅

이미 작성한 코드의 접근 방식, 시간·공간복잡도, 엣지 케이스, 런타임 오류, 실패한 테스트 결과를 기준으로 어디가 문제인지 확인합니다.

오답 기록

왜 틀렸는지, 무엇을 고쳤는지, 다음에 무엇을 기억해야 하는지를 짧게 남겨 한 번의 실패가 다음 문제에 도움이 되도록 만듭니다.

약점 추적

이분 탐색 경계, 그래프 탐색 순서, off-by-one 같은 반복되는 구현 실수를 모아 어떤 부분을 다시 연습해야 하는지 확인할 수 있습니다.

복습 계획

틀린 문제를 저장하고 맥락과 함께 다시 봅니다. 매일 새 문제를 더 푸는 것보다 같은 실수를 줄이는 데 초점을 둡니다.

사용 방식

문제 풀이의 핵심은 그대로 내가 합니다.

01
문제를 엽니다.

LeetCode나 프로그래머스를 평소처럼 사용하면 됩니다.

02
먼저 직접 풀어봅니다.

필요할 때 문제 내용, 현재 코드, 실행 또는 제출 결과를 바탕으로 도움을 받을 수 있습니다.

03
가장 작은 힌트부터 봅니다.

이전 단계로 부족할 때만 더 구체적인 힌트로 넘어갑니다.

04
배운 내용을 남깁니다.

실수 유형과 약점, 복습 항목을 저장해 다음 연습에 다시 사용합니다.

Local-first

학습 기록은 기본적으로 브라우저에 남습니다.

OpenAI API 키, 저장한 코드 스냅샷, 오답 기록, 설정, 로컬 학습 기록은 브라우저에 저장됩니다. AI 요청은 본인의 API 키를 사용해 확장 프로그램에서 OpenAI로 직접 전송됩니다. 계정 및 학습 메타데이터 동기화는 직접 활성화한 경우에만 사용됩니다.

FAQ

설치 전에 궁금할 만한 것들.

LeetCode 정답 코드를 바로 보여주나요?

기본 흐름은 완성된 정답 코드를 즉시 제공하기보다 단계적으로 도움을 주는 방식입니다. 어느 정도까지 힌트를 볼지는 직접 선택합니다.

프로그래머스에서도 사용할 수 있나요?

네. LeetCode와 프로그래머스 문제 페이지를 모두 지원합니다.

OpenAI API 키가 필요한가요?

AI 기능을 사용하려면 필요합니다. API 키는 브라우저에 로컬로 저장되며 요청은 OpenAI로 직접 전송됩니다.

실제 코딩테스트나 채용 시험에서 사용해도 되나요?

아니요. CodeCoach는 연습용 도구이며 진행 중인 대회, 자격시험, 채용 평가, 비공개 시험 등의 답안 작성 용도로 제공되지 않습니다.

다음 문제에서는 정답 검색 전에 힌트 하나만 받아보세요.

LeetCode나 프로그래머스에서 직접 풀어보고, 정말 막힌 지점에서만 필요한 도움을 받으면 됩니다.
