## Detailed description

CodeCoach is an AI coding interview coach for LeetCode and Programmers that helps you get unstuck without immediately giving away the full solution.

Instead of replacing the problem-solving process, CodeCoach works beside the practice page and gives you the smallest useful amount of help: a light hint, an algorithm direction, or a concrete next step. It can also review the code already in your editor, explain selected lines, help debug visible failures, and analyze time and space complexity.

### Practice with progressive AI hints

Choose how much guidance you want:

- Light hint — a small nudge without revealing the main strategy
- Direction hint — points toward the relevant algorithm, data structure, or reasoning shift
- Specific hint — gives a concrete next step without immediately returning a full accepted solution

### Debug and review your current code

CodeCoach can use the visible problem context, editor code, and available run or submission output to help with:

- debugging failed attempts
- code and approach review
- time and space complexity
- edge cases and implementation mistakes
- selected-line explanations
- next-step guidance

### Turn mistakes into a study plan

Solving more problems is not enough if the same mistakes keep repeating. CodeCoach records structured learning signals so you can identify recurring weaknesses such as:

- binary search boundaries
- BFS / DFS traversal mistakes
- sliding-window reasoning
- data-structure selection
- edge cases
- off-by-one errors
- complexity issues

Failed attempts can be saved into a review queue, and wrong-answer notes help turn each mistake into something useful for later practice.

### Built for LeetCode and Programmers

CodeCoach currently supports:

- LeetCode
- Programmers / 프로그래머스

The extension runs directly beside supported coding-practice pages using the Chrome Side Panel.

### Local-first privacy

CodeCoach supports a limited guest trial and bring-your-own-key AI. BYOK requests go directly from the extension to OpenAI using your API key. Guest trial requests go through the CodeCoach Firebase backend to enforce free-use quota, cost controls, and abuse protection. Your OpenAI API key, code snapshots, notes, settings, and local study history are stored in your browser by default.

Optional account and learning-metadata sync is available only when enabled.

CodeCoach does not sell user data or use it for advertising.

### For practice, not active assessments

CodeCoach is designed for coding interview preparation and deliberate practice. It is not intended for active contests, hiring tests, certifications, private assessments, or similar evaluated environments.

CodeCoach is an independent project and is not affiliated with LeetCode, Programmers, OpenAI, Google, or their parent companies.
