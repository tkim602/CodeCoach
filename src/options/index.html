Guardrails

The extension stays scoped to practice pages and avoids storing protected problem content.

This extension works on standard LeetCode and Programmers practice problems. It is disabled on contests, assessments, skill checks, certifications, mock interviews, hiring tests, editorials, and official solution pages.

Problem text, examples, constraints, screenshots, OCR text, page HTML, official explanations, and contest or assessment content are never stored.
